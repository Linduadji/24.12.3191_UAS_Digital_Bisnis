# Laravel CRUD Sample

Ini adalah contoh sederhana struktur CRUD untuk belajar.

- `routes/web.php` - rute resource CRUD
- `app/Models/Item.php` - model data
- `app/Http/Controllers/ItemController.php` - controller CRUD
- `database/migrations/0001_create_items_table.php` - migrasi tabel items
- `resources/views/layout/app.blade.php` - layout dasar
- `resources/views/items/*.blade.php` - tampilan CRUD

> Ini hanya contoh logika sederhana, bukan aplikasi Laravel penuh.
